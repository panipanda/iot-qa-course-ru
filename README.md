# QA для IoT: подготовка к техническому собеседованию

Бесплатный интерактивный курс на русском языке для тестировщика, который отвечает за систему из устройства, облака и мобильного приложения. Рассчитан на неделю подготовки, но работает и как справочник.

Сайт: https://panipanda.github.io/iot-qa-course-ru/

## Что внутри

- **14 модулей** в четырёх частях: как устроен IoT-продукт, что и как тестировать, инструменты и диагностика, процессы и собеседование.
- **План на 7 дней** с отметками выполнения: на каждый день модули, практика, карточки и повторение.
- **Тренажёры практикума**, которые работают в браузере без сервера:
  - учебное облачное API умных ламп с восемью заложенными ошибками (права доступа, валидация, идемпотентность, офлайн-устройства, формат ошибок, токены, утечка данных в ответе);
  - два разбора журналов устройства и облака с фильтром по тексту и регулярным выражениям;
  - подбор параметров повторных подключений после сбоя облака (экспоненциальная задержка и джиттер, «лавина переподключений»);
  - проектирование OTA-обновления против девяти аварий (питание, подпись, откат, версии, постепенная раздача);
  - симулятор потери пакетов для MQTT QoS 0, 1 и 2;
  - калькулятор парных сочетаний (pairwise) для сокращения матрицы тестов;
  - три разбора захватов трафика, клиника отчётов об ошибках и тренажёры сопоставления.
- **112 вопросов** с разбором (один ответ, несколько ответов, порядок, число), в том числе 13 вопросов к разборам журналов, итоговый экзамен на 25 вопросов с подсказкой, что повторить.
- **66 карточек для собеседования** и **глоссарий из 122 терминов**.
- Практическое задание с образцом ответа в каждом модуле.
- Блок «Источники» с проверенными ссылками на первоисточники.

## Для кого

Для инженеров по качеству, которые приходят в IoT из веба, мобильной разработки или backend и хотят закрыть пробелы: протоколы (BLE, Wi-Fi, MQTT, HTTP, gRPC), основы встраиваемых систем, обрывы связи и офлайн, OTA и откат, API, мобильные приложения с оборудованием, логи (UART, syslog, Kibana, Sentry), анализ трафика, базовая безопасность, Python и автоматизация, процессы в командах с железом и подготовка к собеседованию.

## Ваш прогресс остаётся у вас

Прогресс, ответы, записи и результаты заданий хранятся в вашем браузере (`localStorage`, ключ `iot-qa-course-ru.v1`). Ничего не отправляется на серверы, нет аккаунтов, cookie и аналитики, страница не загружает ресурсы с других сайтов.

Что сохраняется: пройденные модули, результаты и ответы на вопросы, отметки на карточках, тексты практических ответов, результаты практикума, отметки плана и последний открытый модуль.

Что не сохраняется намеренно: ввод в мелких тренажёрах и незаконченный итоговый экзамен.

Что нужно знать:

- Прогресс принадлежит одному профилю браузера на одном устройстве и не синхронизируется между телефоном и компьютером.
- Он пропадает, если очистить данные сайта, закрыть приватное окно или сменить браузер. Safari может сам удалить данные сайта примерно через неделю без посещений.
- Кнопка **«Экспорт прогресса»** на главной странице скачивает `progress.json`, кнопка **«Импорт прогресса»** восстанавливает его на другом устройстве и объединяет с тем, что уже есть.
- Не вводите в поля практики ничего конфиденциального: данные работодателя, персональные данные, коммерческую тайну.

Если браузер блокирует хранилище сайта, курс работает, а в шапке написано «Прогресс не сохраняется».

## Ограничения, о которых стоит знать

- **Учебный API и журналы придуманы.** Адреса, имена, значения и последовательности в примерах выбраны для обучения и не описывают реальный продукт.
- **Модели упрощены.** Симулятор повторных подключений считает отказ мгновенным и не учитывает деградацию сервера под нагрузкой; сценарии OTA сведены к девяти типовым авариям. Они учат рассуждать, а не заменяют расчёт для конкретной системы.
- **Курс не заменяет практику.** BLE, UART, питание и радио нужно хотя бы раз потрогать руками: возьмите недорогую плату и телефон с nRF Connect.
- **Протоколы, правила платформ и инструменты меняются.** Разрешения Android и iOS, интерфейсы Sentry и Kibana, синтаксис команд могут отличаться. Сверяйтесь с первоисточниками по ссылкам в модулях. Дата последней проверки указана внизу страницы.
- **Правовые и регуляторные вопросы** (сертификация радиооборудования, защита персональных данных) только упомянуты: ими занимаются специалисты.
- **Безопасность.** Раздел про безопасность даёт базовую гигиену уровня QA, это не руководство по тестированию на проникновение. Проверяйте только свои устройства и тестовые окружения.

## Как запустить у себя

Курс состоит из обычных статических файлов, сборка не нужна.

```text
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Можно открыть и `index.html` напрямую, но через сервер надёжнее.

Тесты (нужен Node.js 20 или новее, внешние пакеты не требуются):

```text
node --test "tests/*.test.js"
```

Тесты проверяют структуру модулей и вопросов, план, источники, модели тренажёров (повторные подключения, MQTT, OTA, парные сочетания, учебное API, журналы вместе с правильными ответами к ним), сохранение и импорт прогресса и отсутствие запросов к другим сайтам.

## Устройство репозитория

| Путь | Что там |
|---|---|
| `index.html` | Единственная страница, порядок подключения скриптов |
| `js/lib.js` | Чистые функции: проверка ответов, состояние прогресса, экспорт и импорт |
| `js/sim.js` | Модели тренажёров без обращения к DOM: сеть, MQTT, OTA, pairwise, учебное API, журналы |
| `js/core.js` | Навигация, вопросы, практика, карточки, экзамен, глоссарий, план |
| `js/widgets.js`, `js/labs.js` | Интерфейс тренажёров |
| `content/ru/` | Тексты модулей, вопросы, карточки, глоссарий, источники, план, данные практикума |
| `tests/` | Тесты |
| `assets/` | Стили и шрифты IBM Plex (лицензия SIL OFL 1.1) |

Язык содержимого лежит в `content/ru/`, чтобы позже можно было добавить другой язык рядом.
